# YouTube Project — YAIL
Independent research software for evaluating publicly documented recommendation-system ideas and forecasting relative video performance. Not affiliated with YouTube. No proprietary platform source code is used.

Read AGENTS.md, CLAUDE.md and research/STATUS.md. Compare reproducible forecasting methods against historical baselines using appropriately licensed data. Distinguish pre-publication from post-publication predictions and Shorts from long-form. No predictive advantage has yet been established.

Public-safe setup only: existing local experiments will be transferred after repository privacy is verified. No private data, internal research artifacts, credentials or unpublished code while public.

Use Python, NumPy, pandas, SciPy and scikit-learn. Develop on separate branches and submit pull requests for owner review. Free tools first; no deployment or paid services without approval.
